# 202372090-Abdulaziz-assignment1

A simple, responsive personal portfolio built with plain HTML, CSS and JavaScript (Assignment 1, SWE363).

## Features
- Sections: About Me, Skills, Projects (2 projects), Contact form
- Responsive layout using CSS Grid and Flexbox (desktop, tablet, mobile)
- JavaScript: time-of-day greeting, dark/light theme toggle (saved in localStorage), smooth scrolling, contact form validation

## Project Structure

## Setup
No installation or build step is needed.
1. Clone the repository: `git clone <repo-url>`
2. Open `index.html` in any modern browser.
